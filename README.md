# _T. cruzi_ Atlas 

To repeat the analysis, it is required to run the Scripts/Atlas/cruzi_qc_data.py then the Scripts/Atlas/atlas_integration_analysis.py scripts. The latter script generates an integrated object which is used for the other analyses scripts. Within the Scripts/Metacyclogenesis folder, please run the cruzi_meta_to_epimast.py script first to generate the pseudotime and count matrix which is required for the tradeSeq script.
